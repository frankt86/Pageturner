# Install

Download the newest Pageturner on your phone:

[:material-download: &nbsp;Download Pageturner](https://frankt86.github.io/Pageturner/pageturner.apk){ .md-button .md-button--primary }

1. Open the link above in your phone's browser, for example Chrome. The file is about 38 MB.
2. If Chrome warns that the file might be harmful, tap **Download anyway**.
3. Open the downloaded file and tap **Install**. If Android asks, allow your browser to install apps.

Pageturner installs as its own app. If you also have Voice from Google Play or F-Droid, both stay on your phone and keep their
own libraries.

The link always gives the newest build. To update, download and install it again over the one you have. Your library and
your place in each book stay.

All builds are listed on the [release page](https://github.com/frankt86/Pageturner/releases/tag/debug).
