# Install

Download the newest stable Pageturner on your phone:

[:material-download: &nbsp;Download Pageturner](https://frankt86.github.io/Pageturner/pageturner.apk){ .md-button .md-button--primary }

All stable versions and their release notes are on the [GitHub Releases page](https://github.com/frankt86/Pageturner/releases).

## Install the APK

1. Open the download link in your phone's browser, for example Chrome.
2. If Chrome warns that the file might be harmful, tap **Download anyway**.
3. Open the downloaded file. Android asks you to allow your browser to install unknown apps. Tap **Settings**, turn on
   **Allow from this source**, and go back.
4. Tap **Install**.

To update by hand, download the file again and install it over the app you have. Your library and your place in each
book stay.

## Get updates with Obtainium

[Obtainium](https://obtainium.imranr.dev/) installs apps from their GitHub releases and tells you about updates.

1. Install Obtainium and open it.
2. Tap **Add App**.
3. In **App Source URL**, enter `https://github.com/frankt86/Pageturner`.
4. Tap **Add**, then **Install**. If Android asks, allow Obtainium to install unknown apps.

Each release has two APK files, `pageturner-<version>.apk` and `pageturner.apk`. They are the same file. If Obtainium asks
which one to install, select either one.

Obtainium only gets the stable releases. It does not get the test app below, unless you turn on **Include prereleases**.

## The test app

Every change to the code also makes a test build:
[pageturner-debug.apk](https://frankt86.github.io/Pageturner/pageturner-debug.apk), also on the
[debug release page](https://github.com/frankt86/Pageturner/releases/tag/debug). It can have new features before a
stable release, and it can have new bugs.

The test app and the stable app are two different apps. You can install both side by side. Each one has its own library,
settings and places in your books. An update of one never changes the other.

The stable app has the same app id as Voice. If Voice from Google Play or F-Droid is on your phone, Android does not
install the stable Pageturner. The test app installs next to Voice.
